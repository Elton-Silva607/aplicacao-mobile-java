# Aplicação Mobile em Java

Este repositório reúne os projetos preparados para os laboratórios das quatro primeiras unidades da disciplina.

- **Unidade 1 — Minha Jornada Mobile:** contador de interações e etapas da jornada.
- **Unidade 2 — Conecta Mobile:** organização de recursos e estrutura de um aplicativo Android.
- **Unidade 3 — Evento Tech:** formulário de inscrição responsivo.
- **Unidade 4 — Jornada Profissional:** navegação entre telas e ciclo de vida.

## Abrir os projetos

Baixe [o arquivo ZIP](aplicacao-mobile-unidades-1-a-4.zip), extraia seu conteúdo e abra a pasta da unidade desejada como projeto Android. Será necessário configurar o Android SDK, Gradle e JDK compatíveis.

**Situação:** os projetos foram preparados, mas ainda não foram compilados nem executados em dispositivo ou emulador; os testes e evidências continuam pendentes.
